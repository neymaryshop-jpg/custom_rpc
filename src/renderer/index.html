Discord

Одно приложение можно использовать и для RPC, и для бота. Тогда название активности и бот будут называться одинаково.

Что я показываю

Аниме, игра или своя тема. Название уходит в строку активности, а GIF — в большую иконку.

—
Категория
Анимированная GIF-иконка
Discord не берёт GIF из локального файла. Нужен публичный https-URL; кнопка загрузки отправит файл на catbox.moe. Рекомендуется 1024×1024.

Войс

Бот читает твой голосовой канал и обновляет строку места. Ссылка становится кнопкой и кликабельным state.

Настройка за 5 минут

                  

                    Одно Discord-приложение = RPC + бот. Если бот не нужен, оставь токен пустым
                    и заполни войс вручную.
                  

                

                
              


              
    
                
  1. 
                  Создай приложение.
                  
                    Developer Portal → New Application. Назови его aruku или как
                    хочешь видеть в статусе. Скопируй Application ID.
                  
                
    2. 
                
  2. 
                  Добавь бота.
                  
                    В приложении → Bot → Add Bot → Reset Token → скопируй токен. Вставь его в
                    поле «Токен бота».
                  
                
    3. 
                
  3. 
                  Пригласи бота на aruku.
                  
                    Кнопка «Пригласить бота» ниже. Нужно право «Просматривать каналы».
                    Без бота авто-войс работать не будет.
                  
                
    4. 
                
  4. 
                  Включи режим разработчика в Discord.
                  
                    Настройки → Расширенные → Режим разработчика. Потом правый клик по серверу →
                    «Копировать ID сервера», по себе → «Копировать ID пользователя».
                  
                
    5. 
                
  5. 
                  Выбери GIF.
                  
                    Нужен прямой https-URL на GIF. Загрузи файл кнопкой на catbox.moe или
                    размести на своём хостинге. Discord анимирует внешние GIF.
                  
                
    6. 
                
  6. 
                  Нажми «Сохранить».
                  
                    RPC подключится к запущенному Discord. Кнопки в своём профиле не видны —
                    это нормально, другие их увидят.
                  
                
    7. 
              


              

                
                
              

            


            

              

                

                  
Плейсхолдеры

                  
Используй их в шаблонах на вкладке «Дополнительно».

                

              

              

                
{P}Название площадки: Twitch, YouTube, Kick…

                
{activity}Что показываешь: Frieren, Minecraft…

                
{server}Сервер: aruku или имя из авто-детекта

                
{voice}Канал: General, Аниме-войс…

                
{place}Готовая строка «aruku / General»

                
{time}«⏱ 3h 12m» или пусто, если таймер стоит

                
{elapsed}«3h 12m» без иконки

              

            


            

              

                

                  
Ограничения Discord

                

              

              
    
                
  • Кнопки RPC не видны автору статуса — только другим пользователям.
    • 
                
  • Загруженные в Developer Portal ассеты статичны; анимация — только через внешний URL.
    • 
                
  • Discord кеширует внешние картинки. Если GIF не обновился — смени URL или добавь ?v=2.
    • 
                
  • Чтобы читать твой войс, бот должен быть на сервере и видеть канал. User-token/self-bot не используется.
    • 
                
  • Ссылка на войс открывает канал в Discord, но не входит в него автоматически.
    • 
                
  • Статус виден, только если в Discord включён показ активности.

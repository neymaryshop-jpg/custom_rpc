# Aruku RPC

Tray-приложение для Discord Rich Presence: показывает, **где ты сейчас**, **что показываешь** и **сколько уже идёт эфир**.

```text
Aruku / General
Смотрю аниме • Frieren • Twitch
2h 14m
[🎧 Войти в войс]  [Aruku]
```

- **Где я** — текущий войс-канал из Discord, с кнопкой-ссылкой. Если Discord не отдал канал — `Aruku/[Voice]`.
- **Что показываю** — аниме/игра/другое, выбор из списка или свой текст. `P` — платформа/подпись (по умолчанию `Twitch`).
- **Время** — живой таймер Discord от начала эфира: `Xh Ym`.
- **Иконка** — анимированный GIF в трее. Для Rich Presence можно указать публичную HTTPS-ссылку на GIF.
- **Tray** — закрытие окна прячет программу в трей, есть автозапуск с Windows.

## Что важно знать про Discord

1. **В Rich Presence только две текстовые строки + таймер.** Третью произвольную строку добавить нельзя. Поэтому используется ровно три визуальных пункта: локация, контент, время.
2. **Анимированный GIF в профиле** работает через внешнюю HTTPS-ссылку (`large_image` URL). Discord может убрать анимацию на своей стороне — тогда останется статичный кадр. В трее GIF анимируется всегда.
3. **Авто-войс** использует локальный Discord RPC `GET_SELECTED_VOICE_CHANNEL`. Discord должен быть запущен. Если канал не определяется, включается ручной резерв или текст `Aruku/[Voice]`.
4. **Ссылка на войс** делается через кнопку и кликабельные `details_url`/`large_url`. Кнопка — самый надёжный вариант. Нужны `Guild ID` и `Channel ID`.
5. Это **не селф-бот** и не сборщик токенов. Приложение общается только с локальным Discord IPC. Токены не нужны.

## Быстрый старт

### 1. Python

Нужен Python **3.10+** для Windows. При установке включи `Add python.exe to PATH`.

### 2. Discord Application

1. Открой [Discord Developer Portal](https://discord.com/developers/applications).
2. `New Application` → назови приложение **Aruku** или **Aruku RPC** (это имя будет сверху в статусе).
3. Скопируй **Application ID** — это и есть `Client ID`.
4. Слева открой **Rich Presence → Art Assets**.
5. Загрузи `assets/rpc-location.png` под именем `aruku_voice`.
6. По желанию загрузи иконки для small image: `anime`, `game`, `media` (можно свои PNG).
7. Подожди пару минут, пока Discord обновит ассеты.

### 3. Запуск

Дважды кликни `run.bat`. Скрипт создаст `.venv`, установит зависимости и запустит приложение без консоли.

При первом запуске откроются настройки. Заполни:

- **Discord Client ID** — Application ID.
- **Название сервера** — `Aruku`.
- **Guild ID** — ID сервера Aruku (в Discord включи Developer Mode → правый клик по серверу → Copy Server ID).
- **Invite-ссылка** — `https://discord.gg/...` для второй кнопки.
- **Авто-войс** — включён.
- **ID войс-канала** — резерв, если авто не сработает.
- **Large image asset** — `aruku_voice`.
- **Large image GIF URL** — публичная HTTPS-ссылка на GIF (необязательно).
- **Small image: аниме/игра/другое** — `anime`, `game`, `media`.

Нажми **«Проверить подключение»**, затем **«Сохранить»**.

### 4. Эфир

В главном окне:

1. Выбери тип: **Аниме / Игра / Другое**.
2. Выбери тайтл из списка или впиши свой.
3. В поле **P** укажи платформу/подпись: `Twitch`, `YouTube`, `Telegram` и т.п.
4. Нажми **«Начать эфир»**.

Таймер пойдёт сразу. Если закрыть окно, приложение останется в трее. Правый клик по иконке — меню.

## Анимированный GIF

### В трее

По умолчанию используется `assets/location.gif`. Чтобы поставить свой:

**Настройки → Иконки → GIF для трея → Выбрать**.

Файл копируется в `%APPDATA%\ArukuRPC\assets\location.gif`, трей сразу перезагружается.

### В Rich Presence

Discord принимает внешнюю картинку по HTTPS. Локальный файл туда подставить нельзя.

1. Загрузи свой GIF на Imgur, GitHub или другой публичный хостинг.
2. Возьми **прямую** ссылку на файл (обычно заканчивается на `.gif`).
3. Вставь её в **Настройки → Иконки → Large image GIF URL**.
4. Сохрани и начни эфир.

Если Discord показывает только первый кадр — это ограничение клиента Discord, а не приложения. В трее анимация при этом работает.

## Ссылка на войс

Авто-режим:

1. Зайди в войс в Discord.
2. Включи **Авто-войс**.
3. Приложение раз в 10 секунд спрашивает у Discord текущий канал.
4. Если канал найден, в статусе появится `Aruku / General`, а кнопка `🎧 Войти в войс` будет вести на `https://discord.com/channels/<guild>/<channel>`.

Если авто не работает:

- укажи **Guild ID** и **ID войс-канала** в настройках;
- или оставь только текст `Aruku/[Voice]` — он появится автоматически.

## Конфиг и логи

- Конфиг: `%APPDATA%\ArukuRPC\config.json`
- Лог: `%APPDATA%\ArukuRPC\logs\aruku-rpc.log`
- Пользовательский GIF: `%APPDATA%\ArukuRPC\assets\location.gif`

Можно переопределить пути переменными окружения:

- `ARUKU_RPC_CONFIG` — путь к JSON-конфигу.
- `ARUKU_RPC_DATA_DIR` — папка для конфига/логов/ассетов.

Пресеты аниме/игр лежат в конфиге в секции `presets`. Их можно править вручную или добавлять кнопкой `＋` в окне.

## Сборка EXE

В PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Готовый файл: `dist\ArukuRPC\ArukuRPC.exe`.

Сборка использует PyInstaller, иконку `assets/icon.ico` и кладёт `assets` рядом с exe.

## Если что-то не работает

- **«Нужен Client ID»** — открой настройки и вставь Application ID.
- **«Discord не запущен»** — запусти Discord для Windows и подожди пару секунд.
- **Авто-войс не видит канал** — выбери канал в Discord, проверь, что Discord не в браузере, или включи ручной резерв.
- **Картинка не появилась** — имя ассета чувствительно к регистру; после загрузки в Developer Portal нужно подождать. Для GIF проверь прямую HTTPS-ссылку.
- **Кнопки не видны** — Discord показывает максимум 2 кнопки, ссылки должны быть `https://`.
- **Таймер не идёт** — нажми «Начать эфир»; время берётся из `timestamps.start`.
- **Трей не анимируется** — проверь, что установлены `Pillow` и `pystray`, и что GIF корректный.
- **Ошибка зависимостей** — запусти `run-console.bat`, там будет текст ошибки.
